# Edutainment 🎓

Edutainment is an interactive multiplication learning game built with SwiftUI. It allows users to practice multiplication through randomly generated questions.

## 📱 Features

- Choose a multiplication table from 2 to 12.
- Select the number of questions: 5, 10, or 20.
- Answer randomly generated multiplication questions.
- Track your score during the game.
- View your final score at the end of the game.

## 🛠 Technologies Used

- Swift
- SwiftUI
- Xcode

While building this project, I practiced:

- Managing app state using `@State`.
- Working with `Stepper`.
- Generating random questions.
- Implementing game logic and score tracking.
- Handling user input.
- Updating the UI dynamically with SwiftUI.
  

## 🚀 Getting Started

1. Clone this repository.
2. Open `Edutainment.xcodeproj` in Xcode.
3. Select an iOS Simulator.
4. Press Run to launch the app.
